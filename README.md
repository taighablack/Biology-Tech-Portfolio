# Biology-Tech-Portfolio
Zoology, Environmental Biology, and Data Science
This repository contains scripts and tools I am developing to bridge the gap between Zoology and Data Science.

### Project 1: Species Data Standardizer (Python)
- **Goal:** Clean messy field observation data.
- **Tools:** Python (String manipulation, Sets for deduplication).
### **Project 2: Biodiversity Database (SQL)**
- **Goal:** Model species observations across ecological habitats.
- **Tools:** PostgreSQL, SQL (JOINs, foreign keys, relational schema design).
